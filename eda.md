## Load the weather data and round date to the first day of the month

``` r
data("weather_df")

weather_df =
  weather_df |> 
  mutate(month = lubridate::floor_date(date, unit = "month"))
```

## `group_by`

``` r
weather_df |> 
  group_by(name, month) |> 
  ungroup(month)
```
